# 경기도 수집 리드의 날짜 필터 누락

## 확인한 코드 경로
sync-engine.ts의 경기도 행 변환은 license_date/last_modified_date를 저장하지 않는다. 기본 searchType은 license_date이고 page.tsx는 최근 3개월 범위를 항상 getLeads에 전달한다. 기존 getLeads의 license_date.gte/lte는 SQL NULL을 제외하므로 날짜 미상 경기 리드가 조회 대상에서 누락될 수 있다.

## 수정 및 범위
기존 최종수정일 조회와 동일하게 인허가일 조회도 범위 조건 또는 날짜 NULL을 허용한다. 날짜가 실제 존재하는 리드의 범위 조건, 조직/RLS·지역·업종·상태·검색·세부 서비스 필터는 유지한다. 수집 데이터를 다시 쓰거나 허위 날짜를 생성하지 않는다.

날짜 미상은 범위와 무관하게 포함되며 날짜 내림차순에서 뒤쪽 페이지에 올 수 있다. 경기만 선택하고 전체 업종/전체 상태/전체 서비스와 빈 검색어로 확인하면 다른 필터 영향을 줄일 수 있다.

## 검증 경계
기존 코드에서 NULL 허용 조건 누락을 회귀 테스트로 재현했다. 인허가일/최종수정일 기준 양쪽의 시작·종료 NULL 허용을 검사한다. 실제 운영 DB 저장 건수와 운영 사이트 반영은 확인하지 않았다. 운영 데이터·스키마·계정·예약 작업은 변경하지 않았다.

검증 결과: 전체 TypeScript 타입 검사, 수정 서비스/테스트 ESLint 검사 통과. 리드 조회·동기화 엔진 관련 테스트 15건 통과. 이번 수정 후 전체 테스트·격리 DB·빌드는 재실행하지 않았으며 운영 배포도 하지 않았다.
