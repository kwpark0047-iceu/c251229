# 관리자 로그인 되돌림 안전 수정

- 계정 상태 조회 오류·프로필 누락·알 수 없는 상태를 실제 SUSPENDED/ARCHIVED와 구분한다. 조회 실패는 화면/API 모두 fail-closed로 유지한다.
- 프로필 조회 실패를 개인정보 없는 분류 코드·추적번호로 기록한다. 최고관리자 플래그나 기존 승인값으로 우회하지 않는다.
- 인증 리다이렉트에 갱신 쿠키를 전달하고 오래된 오류 쿼리를 정리한다.
- 로그인 화면에서 중지/상태조회실패/세션오류를 명시적으로 안내한다.
- 합성 클라이언트 회귀 테스트 RED → GREEN, type-check → lint → 격리 DB 포함 test → build. 운영 계정·DB·키는 사용하지 않는다.
- 운영 로그인 성공의 실제 원인은 운영 프로필 상태/조회 오류 증거가 있어야 확정할 수 있다. 로컬 수정만으로 DB 설정 문제 해결을 주장하지 않는다.
