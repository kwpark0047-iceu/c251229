# c251229 권한 마이그레이션 범위 제한

사용자 확인: 매장 서비스는 별도 Supabase 프로젝트이다. c251229 운영 DB나 매장 DB에 삭제·DDL을 실행하지 않는다.

- [x] 광고 영업 런타임이 참조하는 18개 public 테이블만 회원 보관 정책 대상으로 명시한다.
- [x] Storage는 floor-plans/proposals 버킷만 제한하며 다른 버킷은 기존 정책에 맡긴다.
- [x] 격리 DB에 stores 합성 테이블과 별도 버킷을 두어 RLS/접근이 바뀌지 않는지 재현·검증한다.
- [x] 기존 계정·조직 차단 테스트를 유지한다.
- [x] type-check → lint → 격리 DB 포함 test → build 순서로 검증한다.

기존 마이그레이션 파일은 운영 미적용 준비본을 수정한다. 이미 적용된 DB의 복구를 보장하지 않으며 운영 정책 목록 대조가 별도로 필요하다. 과거 20260323 전역 보안 SQL은 이 작업에서 재실행하거나 자동 수정하지 않는다. 운영 스키마 적용·배포·DB 정리는 별도다.
